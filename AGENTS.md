When creating or updating a LeetAny course, exercise or test case, use the `leetany-course` skill. Follow its instructions for lesson layout, the `.leetany` format and preserving student solutions.
<!-- /leetany:course-skill -->

Keep one folder per course. Write numbered Markdown lessons and one final `99 Practice.leetany` (localize the title for the course). Link each lesson to an exercise by its stable ID or title. Give each task a function signature, an example, an unfinished starter and fixed test inputs with expected return values or exact exception names. Validate new cases locally. Preserve existing exercises and student solutions when extending the course.
