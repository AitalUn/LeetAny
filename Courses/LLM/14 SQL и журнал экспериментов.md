# SQL и журнал экспериментов

Журнал запросов позволяет связать качество и затраты с моделью, промптом и набором данных. Для сравнения нужны run_id, версия данных, конфигурация, длительность, токены, результат и код ошибки. Персональные данные и полный текст промптов не стоит сохранять без необходимости.

## Как это работает

SQL GROUP BY агрегирует строки по ключу; COUNT считает запросы, SUM — токены, AVG индикатора успеха — долю успехов. Важны правила NULL и типы: деление целых и вещественных может отличаться. Параметризованные запросы отделяют данные от SQL. Индекс полезен по реально используемому фильтру; его эффект проверяют планом и измерением. В SQLite учебного набора все поля обязательны, так что NULL исключён контрактом.

## Как применять и проверять

Уметь написать агрегацию SQL, объяснить знаменатель метрики и проверить строки без успехов. Следующее расширение — PostgreSQL, оконные функции и EXPLAIN ANALYZE.
