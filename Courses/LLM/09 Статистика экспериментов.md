# Статистика экспериментов

Разность средних на маленьком наборе может быть случайной. Для сравнения двух конфигураций полезны попарные разности на одних и тех же вопросах: так сложность вопроса частично контролируется. Положительная средняя разность не гарантирует улучшения для всех сегментов.

## Как это работает

В paired bootstrap многократно выбирают с возвращением индексы вопросов и пересчитывают среднюю разность. Percentile-интервал — эмпирическая оценка неопределённости с предпосылками, а не гарантия. Если вопросы сгруппированы по документам, иногда надо ресемплировать группы, а не строки. Перебор множества промптов по одному test превращает test в dev и увеличивает риск ложных находок. Seed нужен для воспроизводимости учебного расчёта.

## Как применять и проверять

Отчёт включает размер набора, эффект, интервал, единицу ресемплирования и ограничения. При интервале через ноль не утверждать уверенное превосходство.

2. Приведи пример из своих проектов или объясни, почему тема там не применялась.
3. Какие данные/метрики понадобятся, чтобы проверить улучшение?
