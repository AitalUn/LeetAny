# LLM-08. Разбиение без утечки

Теория: [[Знания/LLM/Данные и разбиение|Данные и разбиение]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Каждая строка содержит ровно id и group — строки. Все id уникальны; неправильная структура/дубль id → ValueError. Верни train и test как списки ID в исходном порядке: group в test_groups → test, иначе train. Неизвестные группы в test_groups допустимы, их повторы несущественны. Не меняй вход. Эта задача проверяет назначение групп, а не случайный выбор долей.

### Пример

`([{"id":"a","group":"d1"},{"id":"b","group":"d2"}], ["d2"]) → {"train":["a"],"test":["b"]}`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
