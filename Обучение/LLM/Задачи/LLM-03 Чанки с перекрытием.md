# LLM-03. Чанки с перекрытием

Теория: [[Знания/LLM/Подготовка документов и chunking|Подготовка документов и chunking]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Разбей text через str.split() на слова. Первый чанк начинается с 0; после каждого непоследнего сдвиг size-overlap. Добавив чанк, дошедший до конца текста, остановись: дублирующего хвоста не создавать. Внутри чанка слова соединены одним пробелом. size — int>0, overlap — int и 0≤overlap<size; bool недопустим, иначе ValueError. Пустой/пробельный текст даёт [].

### Пример

`("a b c d e", 3, 1) → ["a b c", "c d e"]`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
