# LLM-01. Бюджет контекста

Теория: [[Знания/LLM/Как работает LLM|Как работает LLM]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

token_counts — уже посчитанные количества токенов сообщений; индекс 0 — обязательное системное сообщение. Верни индекс 0 и самый длинный непрерывный суффикс остальных сообщений, помещающийся вместе с ним и reserve в limit. Иди от последнего сообщения назад; если очередное не помещается — остановись, более старые не подбирай. Не меняй вход. Если token_counts пуст — верни []. Числа — неотрицательные int (bool не принимается); отрицательные значения/не-int или обязательное сообщение+reserve>limit дают ValueError. Для пустого списка reserve>limit тоже ошибка.

### Пример

`([4, 6, 3, 2], 12, 2) → [0, 2, 3]`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
