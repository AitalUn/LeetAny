# LLM-11. Политика повторов

Теория: [[Знания/LLM/API, повторы и идемпотентность|API, повторы и идемпотентность]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Для HTTP 429, 500, 502, 503, 504 верни min(cap, base*2**(attempt-1)); для остальных HTTP статусов 100..599 — None. attempt — целый номер неудачной попытки ≥1; base/cap — конечные числа >0; status — int100..599, bool нигде не допускается. Иначе ValueError. При очень большом attempt не допускай переполнения. Функция ничего не ждёт и не делает запросов. Retry-After и jitter вне её контракта.

### Пример

`(429, 3, 0.5, 5) → 2.0`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
