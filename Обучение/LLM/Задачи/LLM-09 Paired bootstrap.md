# LLM-09. Paired bootstrap

Теория: [[Знания/LLM/Статистика экспериментов|Статистика экспериментов]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

deltas — непустой список конечных попарных разностей; n_samples — int>0 (без bool), seed — int. Иначе ValueError. Используй rng=random.Random(seed). Для каждого bootstrap-повтора выбирай len(deltas) индексов через rng.randrange(len(deltas)), вычисляй среднее. Отсортируй средние. low/high — nearest-rank 2.5% и 97.5%: индекс max(0,ceil(p*n_samples)-1). mean — среднее исходных deltas. Верни mean, low, high. Это учебный percentile-интервал, не готовая проверка статистической значимости.

### Пример

`([1, 1], 100, 42) → {"mean":1.0,"low":1.0,"high":1.0}`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
