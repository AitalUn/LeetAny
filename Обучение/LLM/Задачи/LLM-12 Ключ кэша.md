# LLM-12. Ключ кэша

Теория: [[Знания/LLM/Кэш и стоимость|Кэш и стоимость]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Верни SHA-256 hex UTF-8 JSON-объекта с ключами model, prompt, config. Сериализация json.dumps(..., ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False). Порядок ключей config не должен влиять. model и prompt — строки, config — dict с JSON-совместимыми значениями/строковыми ключами; несоответствие → ValueError. Не добавляй соль, дату или сетевой вызов. Версии индекса/прав должны передаваться вызывающим кодом в config.

### Пример

`cache_key("m", "привет", {"temperature":0}) → стабильный 64-символьный hex`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
