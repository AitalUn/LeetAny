# LLM-07. Exact match и token F1

Теория: [[Знания/LLM/Оценка ответов LLM|Оценка ответов LLM]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Нормализация: lower(), затем токены re.findall(r"[^\W_]+", text.lower()) в Unicode; нормализованный текст — токены через пробел. exact_match=1.0 при равенстве нормализованных текстов. F1 — гармоническое среднее precision/recall по мультимножествам токенов. Оба пусты → F1=1; один пуст → 0. Верни ровно exact_match и f1. Синонимы, стемминг и числовой смысл не учитывать.

### Пример

`("Кот, кот!", "кот") → {"exact_match": 0.0, "f1": 2/3}`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
