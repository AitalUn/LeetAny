# LLM-06. Метрики retrieval

Теория: [[Знания/LLM/Метрики retrieval|Метрики retrieval]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Удали дубли ranked с сохранением порядка, возьми первые k. relevant — множество ID независимо от дублей. Верни precision, recall, rr. precision=число найденных релевантных/k, даже если результатов меньше k. recall=найденные/число relevant, при пустом relevant — 0. rr=1/позиция первого релевантного в top-k, либо 0. k — int>0, иначе ValueError; bool недопустим. Возвращаемые ключи ровно precision, recall, rr.

### Пример

`(["x", "a", "b"], ["a", "b", "c"], 2) → {"precision": 0.5, "recall": 1/3, "rr": 0.5}`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
