Теория: [[Знания/LLM/Embeddings и векторный поиск|Embeddings и векторный поиск]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Верни до k ID по убыванию cosine similarity, при равенстве — лексикографически по ID. Нулевой query или документ имеет similarity=0. query должен иметь положительную размерность; все векторы той же длины и состоят из конечных чисел (без bool). k — int≥0, иначе ValueError. documents может быть пустым; k=0 возвращает []. Вход не менять.

### Пример

`([1, 0], {"b": [1, 0], "a": [1, 0], "c": [0, 1]}, 2) → ["a", "b"]`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
