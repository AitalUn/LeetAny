# LLM-10. Валидация tool call

Теория: [[Знания/LLM/Агенты, tools и MCP|Агенты, tools и MCP]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

call имеет ровно поля name (str) и arguments (dict). tools отображает имя tool в словарь аргумент→тип; допустимы типы str, int, bool. Все перечисленные аргументы обязательны; лишние запрещены. Тип проверяется точно: bool не int. Неизвестный tool/тип схемы, неверные поля/типы → ValueError. При успехе верни новый словарь с теми же name и arguments (копия). Ничего не выполняй, не используй eval.

### Пример

`({"name":"search","arguments":{"q":"RAG"}}, {"search":{"q":"str"}}) → тот же вызов`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
