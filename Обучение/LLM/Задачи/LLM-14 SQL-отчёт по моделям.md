# LLM-14. SQL-отчёт по моделям

Теория: [[Знания/LLM/SQL и журнал экспериментов|SQL и журнал экспериментов]] · [[Обучение/LLM/Учебник|Учебник]]

## Задача

Используй sqlite3 и параметризованную вставку в память. Строки содержат ровно model(str), input_tokens(int≥0), output_tokens(int≥0), ok(bool). Неверные поля/типы → ValueError. SQL-агрегацией GROUP BY model посчитай requests, success_rate (число успешных/requests), total_tokens. Верни список словарей с model и этими тремя полями по model ASC. [] → []. Не собирай агрегацию Python-циклом; это проверяется на ревью, а тесты проверяют результат.

### Пример

`две строки модели m с ok=True/False и токенами 2+3, 1+4 → requests=2, success_rate=0.5, total_tokens=10`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
