## Задача

Верни вероятности softmax(logits/temperature). Используй численно устойчивое вычисление. [] даёт []; temperature должен быть конечным числом >0, logits должны быть конечными числами; bool не считается числом. Иначе ValueError. Сумма вероятностей близка к 1, исходный список не меняется. Абсолютная погрешность тестов 1e-8.

### Пример

`([1000, 1000], 1) → [0.5, 0.5]`

### Ограничения

Python 3.10+, только стандартная библиотека. Без сети, API-ключей и загрузки моделей. Чистая функция: не менять аргументы и не выполнять файловые/сетевые действия. Допускаются импорты стандартной библиотеки. Приведи оценку сложности по времени/памяти. Данные тестов открыты — не подгоняй решение под конкретные значения.
