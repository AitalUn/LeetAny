# Метрики retrieval

Для каждого запроса нужен набор релевантных документов или чанков. Precision@k показывает долю релевантных в первых k позициях; Recall@k — долю найденных из всех известных релевантных. Reciprocal rank — 1/ранг первого релевантного результата, либо 0 при его отсутствии. MRR — среднее reciprocal rank по запросам.

## Как это работает

Договорись, считаешь ли документы или чанки: пять соседних чанков одного документа могут создать ложное ощущение разнообразия. Удали повторные ID. Для запросов без релевантных документов отдельно укажи политику метрик и оценивай abstention; незаметно добавлять их с нулём в recall неправильно для сравнения с другой реализацией. В учебном контракте recall пустого множества равен 0, а precision делится на заданный k.

## Как применять и проверять

Не путать документный Recall@k с entity recall для OCR. Добавить срезы по типам запросов, языку и длине документов, а не только общее среднее.
